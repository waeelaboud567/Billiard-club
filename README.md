🎱 Billiard Hall Management System | نظام إدارة صالة بلياردو 🎱

Desktop Application developed using C# لإدارة صالات البلياردو وتنظيم الحجوزات بشكل احترافي وسهل الاستخدام.

✨ Features | المميزات:
🎱 Start / Stop Timer لكل طاولة
⏸️ Pause & Resume أثناء اللعب
💰 Real-time Price Calculation حساب السعر بشكل لحظي
⚙️ Dynamic Price Management تعديل الأسعار بشكل ديناميكي
🧾 Table Reservation by Customer Name حجز الطاولات باسم الزبون
📊 Live Table Status Display عرض حالة الطاولات مباشرة:
🟢 Available
🔴 Occupied
🟡 Reserved
⏸️ Paused

🎯 The system helps manage sessions, reservations, and billing efficiently with a simple and user-friendly interface.

💻 Technologies Used:

* C#
* ADO.NET
* SQL Server
* Windows Forms
